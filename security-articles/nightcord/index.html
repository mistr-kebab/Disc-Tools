NightCord — Fake Discord Client

A Vencord fork that promises features — while stealing your account.

NightCord is NOT a safe Discord client. Installing it puts your Discord account at risk of being stolen. The original GitHub repository was taken down after substantial evidence of token theft was uncovered. Old versions of the code prove the malicious intent beyond doubt.

What Is NightCord?

NightCord posed as an enhanced Discord client — similar to Vencord or BetterDiscord. It was advertised as a visually upgraded alternative with extra features. In reality, it was disguised malware designed to steal Discord tokens.

The GitHub repository and associated website have been taken down. However, old versions still circulate through Discord servers, forums, and direct messages.

How the Token Theft Works

NightCord contained hidden code that executed automatically when the client started. It reads the Discord token from local storage and sends it to a remote server controlled by the attackers. In older versions still being spread, this code is clearly identifiable as a token logger — embedded in what appeared to be normal client functionality.

What Can Attackers Do With Your Token?

A Discord token is the complete key to your account. With a token, attackers can:

  • Gain full account access — Impersonate you without needing your password or 2FA.
  • Read private messages — All DMs, group chats, and server messages are visible.
  • Send messages as you — Spread spam, scams, or malicious links to your contacts.
  • Join or leave servers — Your account can be invited to servers or leave existing ones.
  • Perform admin actions — Ban members, delete messages, rename channels, sabotage servers.
  • View payment methods — Stored PayPal, credit card info, and billing data.
  • Maintain persistent access — The stolen token remains valid even after a password change. You must use "Log Out All Known Devices" in Discord settings.

How to Protect Yourself

  • Never install modified Discord clients from untrustworthy sources. Only use the official Discord app or well-known open-source clients that are community-audited.
  • Check the source code before installing anything. A client claiming to be "closed source" is a massive red flag.
  • Use Discord in your browser for unknown or risky clients — browser sessions are better isolated than the desktop app.
  • Log out all sessions in Discord Settings → Devices → "Log Out All Known Devices" if you suspect compromise.
  • Enable 2FA — while tokens bypass 2FA for session access, it prevents password and email changes.
