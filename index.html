The toolbelt

One box of tools for everything Discord.

Every tool runs in your browser and answers one concrete question. Most run without an account, some need a Discord login, and a few are Premium, available on the dashboard.

01 Look things up

  • User Lookup Badges, account age and details for any user ID.
  • Username History Premium Every past username and discriminator of an account.
  • Server Lookup Members, channels and invites via Discord’s widget API.
  • Invite Lookup Guild info, member count, inviter and expiry of any invite.
  • Alt Account Lookup Premium Find alt accounts linked to a user via IP hash history.
  • Account Checker Account quality score from age, badges and profile signals.
  • Snowflake Decoder Creation date, worker, process and increment from any ID.

02 Create & format

  • Embed Builder Design embeds visually, export the ready JSON payload.Coming soon
  • Markdown Generator Format messages with live preview and quick copy.
  • Timestamp Generator All <t:> formats for any date and timezone.
  • Color Picker Role colors as HEX, RGB, HSL and integer values.

03 Manage & extract

  • Webhook Manager Send messages and delete webhooks without a bot.Coming soon
  • Emoji Stealer High-quality links for any emoji or sticker.
  • Avatar CDN Direct CDN links for any avatar, every size and format.
  • Collectibles Inspector Avatar, banner, decoration, nameplate & clan tag — all CDN links.
  • Link Cleaner Strip fbclid, ttclid, utm_*, is_from_webapp & 60+ trackers. TikTok-ready, bulk.
