Text Formatting

All Discord markdown formatting shortcuts — make your messages stand out.

Bold

Make text stand out with bold formatting.

**text** → text

Italic

Add emphasis with italic formatting.

*text* → text

Underline

Underline text for extra emphasis.

__text__ → text

Strikethrough

Cross out text — great for edits.

~~text~~ → text

Spoiler

Hide sensitive content so users click to reveal.

||text|| → text

Inline Code

Highlight single words with backticks.

`code` → code

Code Block

Multi-line code with syntax highlighting.

```js ⏎code⏎```

Quote

Block quotes and multi-line quoting.

> text / >>> multiline

Subtext

Smaller grey text — perfect for footnotes.

-# subtext

Timestamp

Dynamic timestamps in the viewer's timezone.

<t:unix>
Mentions & References

Channel Mention

Link to a channel so others can jump there.

<#id> → #channel

User Mention

Mention a user by ID to ping them.

<@id> → @user

Role Mention

Ping an entire role using its ID.

<@&id> → @role

Custom Emoji

Use custom emoji from any server your bot is in.

<:name:id>
